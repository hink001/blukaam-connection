Tech Stack

Recommended Architecture

Supabase dual-database design + Next.js 15 for scalable, fast, SEO-friendly performance

DB1
Core Users Database (Supabase)
  • user_id (UUID, Primary Key)
  • name (varchar)
  • phone (unique, indexed)
  • city (varchar)
  • user_type (worker/contractor)
  • created_at, otp_verified
DB2
Profile Details Database (Supabase)
  • user_id (FK → DB1)
  • skills[] + proficiency{}
  • experience[] (JSONB)
  • portfolio_photos[] (Storage)
  • certifications[], reviews[]
  • chart_data{} radar/bar
FE
Frontend – Next.js 15
  • App Router + Server Components
  • Tailwind CSS + shadcn/ui
  • Chart.js for radar/bar charts
  • i18n: Hindi + English
  • PWA – offline + installable
  • Image optimization built-in
BE
Backend & Infrastructure
  • Supabase Auth (OTP/phone)
  • Supabase Storage (photos)
  • Supabase Realtime (alerts)
  • Vercel deployment (CDN)
  • WhatsApp API integration
  • Google Analytics + SEO
